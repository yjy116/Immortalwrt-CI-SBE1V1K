# DAE / DAED 集成补丁

源仓库跟随 [kenzok8/openwrt-daede 的 main](https://github.com/kenzok8/openwrt-daede/tree/main)，构建时记录当次解析的提交。首次核验提交为 `1eedcafd1cd4d8a89ac928be6608df76ffb38f78`，这不是构建固定版本。

- `010` 指定实际 Go 主程序包，补齐 LuCI 翻译构建依赖，安装旧配置迁移，并让前端切换与 CLI/开机启动遵守同一个后端选择。切换先持久关闭两个后端；写入或进程探测失败会明确报错。
- `020` 防止 DAE、DAED、Honk 同时操作共享网络命名空间和 eBPF 资源。另一服务仍运行或进程探测失败时拒绝启动/清理，保留其他服务的资源与用户配置，并将失败状态传回 rc.common。

补丁已按当前源码重制为带上下文的差异，集成脚本先以 `--fuzz=0 --dry-run` 验证，再实际应用；上游布局或逻辑漂移导致不匹配时构建失败，需要重新审阅。

`89-daede-migrate` 只迁移旧订阅定时任务和旧服务入口，备份原 cron，保留数据库与用户代理配置。初始 DAE/DAED 均为禁用。上游组件源码版本、归档与 SHA-256 由其自身配方管理，本仓库不覆盖。

验证运行真实上游 init、清理脚本和 LuCI 后端模块，仅替换路由器 I/O。通过这些检查不代表 SBE1V1K 实机代理、BPF、PPE/NSS 共存或性能已验证。
